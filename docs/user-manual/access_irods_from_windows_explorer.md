Access (read-only) iRODS projects files directly from windows explorer.

(this is done automatically for you in the Windows workplace Campus)

1. Open "File explorer" in Windows
2. Right click on "This PC"
3. Choose "Add a network location"
4. In the "Add network location"-wizard click "Next"
5. (Double)click on "Choose a custom network location"
6. "Internet or network address" fill in: https://davrods.rivm.nl/projects (for acc > https://rivm-bioir-l07a.rivm.ssc-campus.nl/projects)
7. Click "Next" and provide your RIVM credentials in the Windows Security window.
8. For "Type a name for this network location" you can fill in: iRODS projects
9. Click "Next" and then "Finish"

You will see all projects defined in iRODS. You can only assess the files in the projects you have access to.
