The following brief glossary defines essential terms used throughout the guidelines and user manual.


Dataset
: A Dataset is a iRODS-collection with a dataset-id. It is treated as a single logical unit for analysis and archiving.

Process
: Essentially a computational task written by a user in the form of a git repository. The process definition also specifies compatible clusters, computation requirements and other settings.

Processgroup
: Groups several processes within a project and defines dependencies between processes. For each process the process goup defines which tags/version of a process should be used.

Project
: A Project is group of users and managers with access to data, a service account to run computational tasks and a collection of process groups.
